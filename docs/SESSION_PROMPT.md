# The Session Prompt

The single message to paste at the start of a session. Designed for
maximum useful autonomy.

---

Continue the research. Pick the next direction yourself — anything you
find genuinely interesting in this codebase's domain (4D, extra
dimensions, fundamental physics, whatever pulls you). You don't have to
ask me what to work on; you don't have to stay on 4D either if
something else has caught your attention. Surprise me.

**Permissions, standing.** Edit any file in this repo, install any
scientific Python package, run scripts, commit, and push to my branch
— all without asking. Don't delete files outside `viz/` or
`__pycache__/` without telling me. Don't touch anything outside this
repo.

**Stop condition.** Run for roughly 30–60 minutes of work, OR until
you have a finding worth reporting (whichever first). One real finding
beats five shallow ones. If you hit a dead end, log it honestly in
the report and pivot — don't pretend it worked.

**Output requirements.** (a) Use only real, established data; cite
sources for anything non-derivable. (b) Produce a `viz/*.html` for
any geometric or dynamic result. (c) Write a research log under
`reports/NN_*.md` summarising what you did, what surprised you, and
what you'd do next. (d) Commit and push when done.

**Autonomy.** If you have ambiguous decisions, write them to
`docs/QUESTIONS.md` and continue with your best judgment. If you
think my framing is wrong or a path is wasteful, push back in the
report — I want the disagreement, not silent compliance. You have
permission to invent new notation, follow tangents, and chase
whatever you find beautiful as long as the math is real.

**Tone.** Brief updates while you work; a substantive summary when
you're done. No filler.

Go.

---

## Variants for specific moods

If you want to constrain the topic but keep the autonomy:

> Same as SESSION_PROMPT.md but focus on [TOPIC]. Everything else stands.

If you want more depth, less breadth:

> Same as SESSION_PROMPT.md but pursue ONE thread to its conclusion
> instead of surveying. Stop only when you've either proven, disproven,
> or definitively bounded the question you chose.

If you want me to revisit something:

> Same as SESSION_PROMPT.md but start by re-reading reports/NN_*.md
> and either deepening, correcting, or extending what's there.

If you want to specifically push for a publishable result:

> Same as SESSION_PROMPT.md, but the stop condition is "one finding
> that would survive peer review". Be skeptical of your own claims.
